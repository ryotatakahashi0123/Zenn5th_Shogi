## 説明文（対象ユーザー像と課題、ソリューションと特徴）

**対象と課題**
将棋アプリで指す中級者（初段前後）。既存の解析サービスでも、評価値のグラフや悪手の一覧で「どこで形勢が傾いたか」は見える。しかし、(1) 見えるだけで次に何を直すかが決まらない、(2) 悔しかった手と、実際に形勢を壊した手がずれていても気づけない、(3) 振り返りが手元に残らない、という困りごとが残る。発案者自身（将棋ウォーズ初段・歴10年）の経験から出た課題である。

**ソリューション**
棋譜を入れると、まず本人が局面図を見ながら「悔しかった手」と「好手」に印を付け、原因を選ぶ。解析結果は、この入力を終えるまで見せない。そのあと将棋エンジン（やねうら王 + 水匠5）の全手解析と突き合わせ、決まった規則で「一致／感覚だけ／データだけ」に分けて、感覚とデータのずれを見せる。AIコーチ（Gemini + ADK）が勝負どころを自分で選んでエンジンで深く調べ、ふりかえりを書く。結果はA4のノート（PDF）にまとまり、前半が局面図の問題、後ろが回答（最善手と読み筋）になる。

**特徴**
- 数値（勝率、最善手、読み筋）はすべてエンジンと決まった規則が出し、AIは数値を作らない。AIが決めるのは、どの局面を調べるか、どの道具を使うか、どう言葉にするか
- 悔しさの印は本人が付ける。AIは代わりに付けない
- 棋譜を読み込むと、解析 → AIコーチのふりかえり → 保存 が、ボタンを押さなくても裏で進む
- 本人が同意した対局だけを保存し、あとから開き直せる。保存した対局から傾向（選んだ原因、悪手候補が出た段階、自分で気づけた数）を集計し、AIコーチが次のふりかえりで使う
- エージェントの道具は許可リストで固定（Web検索なし、回数の上限あり）。呼んだ道具は画面とCloud Loggingに記録する。エンジンのAPIは非公開（IAM認証）で、GeminiはAPIキーを使わずサービスアカウントで呼ぶ

**使用技術**
Cloud Run（shogi-web / shogi-engine）、Gemini（Vertex AI）、Agent Development Kit、Cloud Storage、Cloud Logging、Streamlit、FastAPI、やねうら王 + 水匠5、cshogi

## 動作確認の方法（下書き）

1. 上のURLを開き、次のテストアカウントでログインする
   - 利用者名: 【審査用の利用者名】
   - パスワード: 【審査用のパスワード（ダッシュボードにだけ書く）】
2. 最初の画面の「保存した対局」に、サンプルの対局がある。「開く」を押すと、解析結果（ずれの表、形勢グラフ、局面図、悪手候補、好手、AIコーチのふりかえり）が表示される
3. 新しく試すときは「棋譜を入力する」を押す。棋譜ファイル（KIF / CSA）の読み込み、テキストの貼り付け、画面の将棋盤での入力のどれかで棋譜を入れる
4. 「この棋譜でふりかえりを始める」→ 局面図を手送りして、悔しかった手・好手に印を付ける →「入力を完了して解析結果を見る」
   （印を付けずに試すときは「印を付けずに、すぐ解析結果を見る」）
5. 解析結果が出て、右側でAIコーチのふりかえりが自動で始まる（30秒〜1分ほど）。下の入力欄から質問できる（例: 15手目で３四飛ならどうだった？）
6. 「ふりかえりノート」の「PDFをダウンロード」で、ノートを保存できる

補足
- 初回のアクセスは、起動に時間がかかることがある（しばらく使われていないと、サービスが止まった状態から起動するため）
- 解析は1手あたり0.4秒が既定。100手の棋譜で1分ほど
- スマートフォンの幅には対応していない。PCのブラウザで確認してほしい
