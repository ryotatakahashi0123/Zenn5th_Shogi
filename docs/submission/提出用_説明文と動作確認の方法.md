## 説明文（対象ユーザー像と課題、ソリューションと特徴）

**対象と課題**
将棋アプリで指す中級者（初段前後）。既存の解析サービスでも、評価値のグラフや悪手の一覧で「どこで形勢が傾いたか」は見える。しかし、(1) 見えるだけで次に何を直すかが決まらない、(2) 悔しかった手と、実際に形勢を壊した手がずれていても気づけない、(3) 振り返りが手元に残らない、という困りごとが残る。発案者自身（将棋ウォーズ初段・歴10年）の経験から出た課題である。

**ソリューション**
棋譜を入れると、まず本人が局面図を見ながら「悔しかった手」と「好手」に印を付け、原因を選ぶ。解析結果は、この入力を終えるまで見せない。そのあと将棋エンジン（やねうら王 + 水匠5）の全手解析と突き合わせ、決まった規則で「一致／感覚だけ／データだけ」に分けて、感覚とデータのずれを見せる。AIエージェント（Gemini + ADK）が勝負どころを自分で選んでエンジンで深く調べ、ふりかえりを書く。結果はA4のノート（PDF）にまとまり、前半が局面図の問題、後ろが回答（最善手と読み筋）になる。

**特徴**
- 数値（勝率、最善手、読み筋）はすべてエンジンと決まった規則が出し、AIは数値を作らない。AIが決めるのは、どの局面を調べるか、どの道具を使うか、どう言葉にするか
- 悔しさの印は本人が付ける。AIは代わりに付けない
- 棋譜を読み込むと、解析 → AIエージェントのふりかえり → 保存 が、ボタンを押さなくても裏で進む
- 本人が同意した対局だけを保存し、あとから開き直せる。保存した対局から傾向（選んだ原因、悪手候補が出た段階、自分で気づけた数）を集計し、AIエージェントが次のふりかえりで使う
- エージェントの道具は許可リストで固定（Web検索なし、回数の上限あり）。呼んだ道具は画面とCloud Loggingに記録する。エンジンのAPIは非公開（IAM認証）で、GeminiはAPIキーを使わずサービスアカウントで呼ぶ

**使用技術**
Cloud Run（shogi-web / shogi-engine）、Gemini（Vertex AI）、Agent Development Kit、Cloud Storage、Cloud Logging、Streamlit、FastAPI、やねうら王 + 水匠5、cshogi

## 動作確認の方法（下書き）

審査用のテストアカウント `exam` には、**保存した対局が2局**入っている（個人情報に配慮して、2局だけにしている。
対局者名の無い棋譜。2026-10-15 に保存。保存した対局は30日で自動的に消えるので、12/1 の最終ピッチの前に入れ直す必要がある）。

| | 1局目（一覧の上。`kifu_….kif`） | 2局目（一覧の下。盤面で入力した棋譜） |
| --- | --- | --- |
| 手数・自分の手番 | 40手・先手（▲） | 11手・後手（△） |
| 付けた印 | 15手目に「悪手だと思った」（原因: 焦り・早指し／時間不足／定跡・形を知らなかった） | なし（印を付けずに解析） |
| エンジンとの突き合わせ | 15手目はエンジンでも悪手 →「一致」。自分の好手候補2つと相手の好手候補1つは「データだけ」 | 自分の悪手候補2つ（4手目 緩手、10手目 悪手）と相手の悪手候補1つが「データだけ」 |
| AIエージェント | ふりかえりの講評あり | ふりかえりの講評あり |

1. 上のURLを開き、次のテストアカウントでログインする
   - 利用者名: `exam`
   - パスワード: 【ダッシュボードにだけ書く】
2. 最初の画面の「これまでの記録」で、2局を決まった規則で数えた結果を見る
   - 自分の悪手候補の割合 12%（自分が指した手のうち、エンジンが悪手・疑問手・緩手とした手の割合。100%なら全部の手、0%なら悪手候補なし）
   - うち、自分で気づけた割合 33%（悪手候補3つのうち、解析を見る前に「悪手だと思った」印を付けていた1つ）
   - 悪手候補が出た段階: 序盤 11%・中盤 11%・終盤 14%（序盤・中盤・終盤の順で固定）
   - 選んだ原因: 焦り・早指し／時間不足／定跡・形を知らなかった（各1回）
3. その下の「大会に向けた傾向まとめ」で、記録から言えること（規則で数えた結果）と、AIの所感（Gemini。記録に無い数字を含む行は除く）、
   規則で選んだ局面例（3つ）を見る。「PDFをダウンロード」で、A4のまとめ（3ページ以内）を保存できる
4. 「保存した対局」の1局目（40手）の「開く」を押す。解析はやり直さず、保存した結果をそのまま表示する
   - 左に形勢グラフと局面図、右にAIエージェントのふりかえり。講評の中の「15手目」などを押すと、局面図がその手に移る
   - 下の「ラベルごとのふりかえり」（6つのタブ）の「自分の手・悪手だと思った」で、15手目が「一致」に入っている。
     「読み筋を盤で見る」で、最善手からの読み筋と実戦の手からの読み筋を1手ずつ盤で確かめられる
   - 「ふりかえりノート」の「PDFをダウンロード」で、A4のノート（前半が局面図の問題、後ろが回答）を保存できる
   - 下の入力欄から質問できる（例: 15手目で別の手ならどうだった？）。AIエージェントはエンジンで確かめてから答える（30秒〜1分ほど）
5. 「最初の画面に戻る」で戻り、2局目（11手）の「開く」を押す。印を付けなかった対局でも、エンジンが見つけた悪手候補が
   「自分の手・悪手だと思った」タブの「データだけ」（気づかなかった悪手）に出る
6. 新しく試すときは、最初の画面の「棋譜を入力する」を押す
   1. 棋譜ファイル（KIF / CSA）の読み込み、テキストの貼り付け、画面の将棋盤での入力のどれかで棋譜を入れる
   2. 「あなたは先手ですか、後手ですか？（必須）」を選び、「この棋譜でふりかえりを始める」を押す
   3. 局面図を手送り（← → キーでも可）して、気になった手だけ、ラベル（自分の手: 悪手だと思った／ほかにも指す手があった／好手だと思った、
      相手の手: 悪手だと思った／予想外で驚いた／好手だと思った）を選んで「この印を付ける」。原因・コメント・迷った別の読みは任意
   4. 「入力を完了して解析結果を見る」（印を付けずに試すときは「印を付けずに、すぐ解析結果を見る」）。解析結果は、印の入力を終えるまで見せない
   5. 解析結果が出ると、AIエージェントのふりかえりが自動で始まる
   - 保存に同意すると、この対局も「保存した対局」と「これまでの記録」に加わる。試すだけなら、保存しないことを選べる

補足
- 初回のアクセスは、起動に時間がかかることがある（しばらく使われていないと、サービスが止まった状態から起動するため）
- 解析は1手あたり0.4秒が既定。100手の棋譜で1分ほど
- 評価はエンジンによる参考値。PCのブラウザで確認してほしい（スマートフォンの幅では縦に並ぶが、細かい確認はしていない）
