### プロジェクト概要（200〜300字程度）

```
将棋の解析ソフトは悪手と好手を示しますが、本人が「ここで負けた」と考えた手が実際にどうだったのかは教えてくれません。プロや強い人と感想戦をする機会も多くありません。ふりかえり将棋は、答えを見る前に本人が手に印を付け、その感覚とエンジンの判定のずれを見せます。自分の手には「悪手だと思った・ほかにも指す手があった・好手だと思った」、相手の手には「悪手だと思った・予想外で驚いた・好手だと思った」の印を付けます。そのあと、決まった規則でエンジンの判定と突き合わせ、AIコーチがずれた局面をエンジンで調べ直して講評を書きます。対局をまたいだ癖も集計し、次の一局で直すことを決められるようにします。
```

## タブ「プロジェクト紹介」

### 課題と解決（800字まで）

```
本システムの対象は、将棋アプリや対面で指した対局の棋譜を入れて、振り返りのやり方を変えたい人です。解析ソフトの発達で、どこで形勢が傾いたかは誰でも分かるようになりました。それでも、上達につながる振り返りには次の3つが足りません。

1. 自分の考えのどこがずれていたかが分からない
・解析を見ても「ここが悪手」と知るだけで終わる（作者の実体験：敗着だと思った手は好手で、本当の悪手は別の手だった）
・プロや強い人との感想戦のように、自分の考えを確かめてもらう機会はほとんどない
（解決）
・答えを見る前に印を付ける：自分の手と相手の手に6つのラベルで印を付け、原因・コメント・迷った別の読みも残します。解析結果は印を付け終えるまで見せません
・ずれを見せる：エンジンの全手解析と突き合わせ、決まった規則で「一致／感覚だけ／データだけ」に分けます

2. 同じ間違いを繰り返しても、自分の癖に気づけない
・1局ずつ見るだけでは傾向が分からず、表計算で集計するのは手間がかかる
（解決）
・AIコーチが一緒に振り返る：ずれた局面をエンジンで調べ直してから講評を書き、質問にも答えます
・対局をまたいで集計する：保存した対局から、選んだ原因の傾向や、悪手に自分で気づけた数を集計します

3. 解析結果は、アプリを開かないと見返せない
（解決）
・手元に残す：局面図の問題と回答（最善手と読み筋）を、A4のノート（PDF）にまとめます
```

### アーキテクチャ説明（800字まで）

```
構成
・Cloud Run「shogi-web」（公開）：画面（Streamlit）と、Agent Development Kit で作ったAIコーチを動かします。Gemini（Vertex AI）はサービスアカウントで呼ぶため、APIキーを持ちません
・Cloud Run「shogi-engine」（非公開）：やねうら王と水匠5をFastAPIで提供します。IAM認証が必須で、shogi-webのサービスアカウントだけが呼べます
・Cloud Storage：本人が同意した対局だけを利用者ごとに保存し、30日で自動削除します。パスワードは保存せず、ハッシュだけを置きます
・Cloud Logging：AIコーチが呼んだ機能の開始・終了・所要時間・エラーを記録します
・Cloud Build：2つのサービスのイメージを作り、1本のスクリプトでデプロイします

設計上の工夫
・数値はエンジン、言葉はGemini：評価値を勝率に直し、指した側の勝率が20%以上下がれば悪手、10%なら疑問手と規則で判定します。AIが決めるのは、調べる局面、使う機能、言葉づかいです
・AIの役割を固定：全手の形勢、印とのずれ、過去の傾向、局面の深掘り（6局面まで）、手の比較（10回まで）の5つだけを使い、Web検索はしません
・AIの出力を確かめる：傾向まとめは、材料に無い数字を含む行や長すぎる行を捨ててから表示します
・個人情報の保護：コメントを命令として扱わないよう指示し、対局者名はモデルに送りません
・AIに依存しない：AIの呼び出しが失敗しても、エンジンの結果とずれの表は表示します
・試験済み：突き合わせ・集計・ノート・棋譜の読み込みは画面から切り離した関数にし、GitHub Actions で自動試験しています
```

### 動作確認の方法

```
1. ログイン
デプロイURLを開き、次のテストアカウントでログインします。
利用者名: exam
パスワード: 【審査用のパスワード（ダッシュボードにだけ書く）】

2. まず結果を見る（1分）
最初の画面の「保存した対局」に、サンプルの対局が2局あります。「開く」を押すと、解析結果（ラベルごとのふりかえり、形勢グラフ、局面図と読み筋、悪手候補、AIコーチのふりかえりと質問・回答）が表示されます。
・sample_game1.kif：「悪手だと思った」「好手だと思った」の印を付けた対局（一致1、感覚だけ1）
・sample_game2.kif：印を付けずに解析した対局
「ふりかえりノート」の「PDFをダウンロード」で、ノートを保存できます。

3. 新しく試す（3〜5分）
「棋譜を入力する」を押します。棋譜の入れ方は3つあります。
・KIF / CSA のファイルを読み込む（リポジトリの sample.kif が使えます）
・棋譜のテキストを貼り付ける
・画面の将棋盤で1手ずつ指し、「投了」を押す
「あなたは先手ですか、後手ですか？」で自分の手番を選び（必須）、「この棋譜でふりかえりを始める」を押します。局面図を手送りして、気になった手に6つのラベルのどれかで印を付けます（原因・コメント・迷った別の読みは任意）。「入力を完了して解析結果を見る」を押すと、結果が表示されます。
印を付けずに試すときは「印を付けずに、すぐ解析結果を見る」を押します。保存にチェックが無いと確認が出ますが、どれを選んでも進めます。

4. AIコーチ
解析結果が出ると、右側でAIコーチのふりかえりが自動で始まります（30秒〜1分ほど）。下の入力欄から質問できます（例：15手目で3四飛ならどうだった？）。「エージェントの行動ログ」で、AIコーチが呼んだ機能を確認できます。

5. 補足
・しばらく使われていないと、最初のアクセスは起動に時間がかかります
・解析は1手あたり0.4秒が既定です（棋譜の長さにより10秒〜1分ほど）。左のバーで変えられます
・PCのブラウザで確認してください（スマートフォンの幅には対応していません）
・サンプルの棋譜は、将棋エンジン同士の対局から作ったものです
・保存した対局は30日で自動的に削除されます
```
