### プロジェクト概要（200〜300字程度）

```
将棋の棋譜を入れると、まず自分で「悔しかった手」と「好手」に印を付け、そのあと将棋エンジンの解析と比べて、感覚とデータのずれを見せるWebサービスです。解析結果は、印を付け終えるまで見せません。AIコーチ（Gemini + ADK）が勝負どころを自分で選んでエンジンで調べ、ふりかえりを書きます。結果は局面図つきのノート（PDF）にまとまります。本人が同意した対局は保存され、選んだ原因などの傾向が次のふりかえりに使われます。数値はすべてエンジンと決まった規則が出し、AIは数値を作りません。
```

## タブ「プロジェクト紹介」

### 課題と解決（800字まで）

```
**課題**

将棋アプリで指す中級者（初段前後）が対象です。既存の解析サービスでも、評価値のグラフや悪手の一覧で「どこで形勢が傾いたか」は見えます。それでも次の困りごとが残ります。作者自身（将棋ウォーズ初段・歴10年）の経験から出た課題です。

- 見えるだけで、次に何を直すかが決まらない
- 悔しかった手と、実際に形勢を壊した手がずれていても気づけない
- アプリを閉じると、振り返りが手元に残らない

**解決**

- **答えを見る前に、自分で印を付ける**: 局面図を見ながら、悔しかった手と好手に印を付け、原因を選びます。解析結果は、この入力を終えるまで見せません
- **ずれを見せる**: 将棋エンジンの全手解析と突き合わせ、決まった規則で「一致／感覚だけ／データだけ」に分けます
- **AIコーチが自分で調べる**: 本人の印と形勢の動きから調べる局面を自分で選び、エンジンで深く読んでから、ふりかえりを書きます。質問にも、エンジンで確かめてから答えます
- **手元に残す**: 局面図の問題と回答（最善手と読み筋）をA4のノート（PDF）にします
- **続けるほど傾向が分かる**: 同意した対局を保存し、選んだ原因や、悪手候補に自分で気づけた数を集計して、次のふりかえりに使います

棋譜を入れたあとは、解析・ふりかえり・保存がボタンを押さなくても裏で進みます。指し手の良し悪しや勝率はすべてエンジンと決まった規則が出し、AIは数値を作りません。悔しさの印を付けるのは、いつも本人です。
```

### アーキテクチャ説明（800字まで）

```
**構成**

- **Cloud Run「shogi-web」（公開）**: 画面（Streamlit）とAIコーチ（Agent Development Kit）。GeminiはVertex AIをサービスアカウントで呼び、APIキーを持ちません
- **Cloud Run「shogi-engine」（非公開）**: 将棋エンジン（やねうら王 + 水匠5）をFastAPIで提供します。IAM認証が必須で、shogi-webのサービスアカウントだけが呼べます
- **Cloud Storage**: 本人が同意した対局だけを利用者ごとに保存し、30日で自動削除します。パスワードは保存せず、ハッシュだけを置きます
- **Cloud Logging**: エージェントが呼んだ道具の開始・終了・所要時間・エラーを記録します

**設計上の工夫**

- **数値はエンジン、言葉はGemini**: 勝率・最善手・読み筋はエンジンの出力で、区分（一致／感覚だけ／データだけ）は決まった規則で決めます。AIが決めるのは、どの局面を調べるか、どの道具を使うか、どう言葉にするかです
- **道具は許可リストで固定**: 全手の形勢、印とのずれ、過去の傾向、局面の深掘り（6局面まで）、手の比較（10回まで）の5つだけです。Web検索は持たせていません
- **本人の入力はデータとして扱う**: コメントを命令として扱わないよう指示し、対局者名はモデルに送りません
- **止まらない**: AIが失敗しても、エンジンの結果とずれの表は表示します
- **試験**: 規則の部分（突き合わせ、集計、ノート、棋譜の読み込み）は画面から切り離した関数にし、自動試験を付けています
```

### 動作確認の方法

```
1. デプロイURLを開き、次のテストアカウントでログインします。
   利用者名: shinsa
   パスワード: 【Cloud Shell の ~/zenn5th_shinsa_password.txt の中身】

2. 最初の画面の「保存した対局」に、サンプルの対局が2局あります。
   「開く」を押すと、解析結果（感覚とエンジンのずれ、形勢グラフ、局面図と読み筋、悪手候補、好手、AIコーチのふりかえりと質問・回答）が表示されます。
   「ふりかえりノート」の「PDFをダウンロード」で、ノートを保存できます。
   - sample_game1.kif: 悔しかった手と好手に印を付けた対局（一致1、感覚だけ1）
   - sample_game2.kif: 印を付けずに解析した対局

3. 新しく試すときは「棋譜を入力する」を押します。棋譜の入れ方は3つあります。
   - KIF / CSA のファイルを読み込む（リポジトリの sample.kif が使えます）
   - 棋譜のテキストを貼り付ける
   - 画面の将棋盤で1手ずつ指し、「投了」を押す

4. 「この棋譜でふりかえりを始める」を押し、局面図を手送りして、悔しかった手・好手に印を付け、「入力を完了して解析結果を見る」を押します。
   印を付けずに試すときは「印を付けずに、すぐ解析結果を見る」を押します。
   保存にチェックが無いと確認が出ます。どれを選んでも進めます。

5. 解析結果が出ると、右側でAIコーチのふりかえりが自動で始まります（30秒〜1分ほど）。
   下の入力欄から質問できます（例: 15手目で３四飛ならどうだった？）。
   「エージェントの行動ログ」で、AIコーチが呼んだ道具を確認できます。

補足
- しばらく使われていないと、最初のアクセスは起動に時間がかかります。
- 解析は1手あたり0.4秒が既定です（棋譜の長さにより、目安で10秒〜1分ほど）。
- PCのブラウザで確認してください（スマートフォンの幅には対応していません）。
- サンプルの棋譜は、将棋エンジン同士の対局から自作したものです。
- 保存した対局は30日で自動的に削除されます（サンプルは 2026-10-13 に保存）。
```
