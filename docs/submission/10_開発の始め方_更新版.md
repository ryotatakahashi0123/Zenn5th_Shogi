# 開発を始めるときの手順（毎回）― 更新版

最終更新: 2026-10-13 / 対象: いま公開している版（Cloud Shell の `~/zenn5th_shogi`。Streamlit + ADK）
元の `10_開発の始め方.md` は FastAPI 版（`~/Zenn5th_Shogi`）の手順で、この版では動かない。

Cloud Shell は、しばらく触らないと接続が切れてサーバーが止まる。止まったら、この手順をやり直す。

## 1. 場所とプロジェクトを確かめる

```bash
cd ~/zenn5th_shogi                 # ls で app.py と README.md が見えること
gcloud config get-value project    # zenn5thshogi と出ること
```

`(unset)` と出たら次を実行する。**これが空だと、AIエージェントの欄が「使えません」の表示になる**（2026-10-13 に実際に起きた）。

```bash
gcloud config set project zenn5thshogi
export GOOGLE_CLOUD_PROJECT=zenn5thshogi
```

## 2. Python 環境と試験

```bash
. .venv/bin/activate
python -m pytest -q                # 36件通ること（2026-10-13 時点）
```

環境が無い場合:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt -r engine_service/requirements.txt pytest
```

`engine/`（やねうら王と `eval/nn.bin`）が無ければ、README の手順1で作る。試験が通らない状態で作業を始めない。

## 3. 動かして確かめる

```bash
export GOOGLE_CLOUD_PROJECT="${GOOGLE_CLOUD_PROJECT:-zenn5thshogi}"
streamlit run app.py --server.port=8080 --server.enableCORS=false --server.enableXsrfProtection=false
```

- 「ウェブでプレビュー」→「ポート 8080 でプレビュー」で開く
- ログインが要る。手元の利用者は `data/auth/users.json` にある。追加は `python tools/add_user.py <利用者名>`（パスワードは画面に出さずに聞かれる）
- 手元では、保存に同意した対局は `data/` フォルダーに入る（自動では消えない。git に入れない）
- この起動では、AIエージェントは本物の Gemini を呼ぶ（費用がかかる）
- 止めるときは `Ctrl+C`

## 4. Google Cloud に出す

```bash
python -m pytest -q
PROJECT_ID=zenn5thshogi bash deploy/setup.sh     # 10分ほど。2つのイメージのビルドと、2つのサービスのデプロイ
```

- 公開URL: https://shogi-web-4u4mgk5qka-an.a.run.app
- 課金される公開サービスを更新する操作なので、実行は発案者の判断で行う
- 公開サービスの利用者を追加・パスワードを変えるとき:
  `BUCKET=zenn5thshogi-shogi-games GOOGLE_CLOUD_PROJECT=zenn5thshogi python tools/add_user.py <利用者名>`
- 出したあと、URL を開いて、ログイン → 棋譜の読み込み → 解析 → AIエージェント → 保存した対局を開く、までを一度通す
- 数局動かしたら、請求画面で実額を見る（反映は数時間〜1日遅れる）。予算アラートがあることを確かめる

## 5. やってはいけないこと

- トークン、パスワードを、チャット・コード・コミットに書かない。漏れたら、すぐ変える
- 対局相手の名前・IDが入った棋譜、`data/` フォルダーを、リポジトリや動画に出さない
- 提出後（12/1 まで）、`main` を変更しない。リポジトリの連携を外さない。デプロイを止めない
- `git push -f`（強制push）をしない
- 請求・クーポンに関わる設定を、他の人に渡さない

## 6. Claude に頼むとき

- 最初に `CLAUDE.md` を読ませる（守ること、構成、いまの決まりが書いてある）
- エラーは、出力をそのまま貼る（秘密が入っていないか確認してから）
- 数字や判定（しきい値、区分の条件）を変える依頼は、理由も伝える。試験の期待値が変わるため

## 7. 困ったとき

| 症状 | 見る所 |
|---|---|
| AIエージェントの欄が「使えません」 | `GOOGLE_CLOUD_PROJECT` が空。手順1の `export` を入れて起動し直す |
| `pytest` が通らない | 出力の最初の失敗を貼る。`engine/` があるか、`.venv` を有効にしたか |
| 画面が開かない | サーバーが止まっていないか、ポートが 8080 か |
| ログインできない | 5回続けて間違えると5分止まる。利用者が無ければ `tools/add_user.py` で作る |
| 公開サービスでAIエージェントが失敗する | `gcloud run services logs read shogi-web --region asia-northeast1 --limit 50` |
| エンジンの解析に失敗する | `gcloud run services logs read shogi-engine --region asia-northeast1 --limit 50` |
