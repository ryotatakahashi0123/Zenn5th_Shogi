# 判断記録(設計資料からのずれと、その理由)

| ID | 内容 | 状態 |
|---|---|---|
| D-1 | 画面はフレームワークなしの静的HTML/JS(`app/static`)。FastAPIが配信 | 確定 |
| D-2 | 認証は共有デモアカウント1つ(uid=`demo`)+署名つきクッキー。審査員向け。個人データを溜める用途には使わない | プロトタイプ |
| D-3 | ADKは**未接続**。`app/agent/adk_agents.py` は説明だけのスタブ。LLM呼び出しは `google-genai`(Vertexモード)直接。「ADKを使った」と書かない | 要判断 |
| D-4 | 評価値なしが主経路。「考える問題」は局面を出して本人が考える形で、正解手は持たない(`bestMove=None`) | 確定 |
| D-5 | 実行を2回に分け、間に人の印づけを挟む。エージェントは印を付けない | 確定 |
| D-6 | 盤はUI用にサーバー生成のSVG(`<img>`)、PDF用に別実装(reportlabで直接描画)。描画が二重になっている | 要整理 |
| D-7 | 本人のメモ(`note`)はLLMに送らない(命令混入と個人情報送信を避ける)。レポート本文には出る | 確定 |
| D-8 | PDFの日本語はCIDフォント(HeiseiKakuGo-W5)が既定。埋め込まれない。`fonts/` にTTFを置けば埋め込む | 要確認 |
| D-9 | 保存先はCloud Storage(2026-10-12決定)。30日の自動削除はバケットのライフサイクル規則(全ファイルに効く)。Firestore版は残すが既定ではない。実際のバケットでは未実行 | 実装済み・実機未確認 |
| D-12 | 審査用に、1日の実行回数と保存件数の上限を既定でなしにした(`DAILY_RUN_LIMIT=0`、`MAX_GAMES_PER_USER=0`)。費用は1日の全体上限 `DAILY_COST_CAP_USD`(既定3ドル。D-11で当初1ドルとしたのを変更)で守る。上限に達するとAIが使われず、審査員には規則による要約が出る | 要見直し(提出後) |
| D-11 | 費用管理: 実行ごとにトークン数と概算費用を記録し、全体の1日合計が `DAILY_COST_CAP_USD`(既定1ドル)に達したらAIを使わず規則による要約にする。単価は `PRICE_IN_PER_M` / `PRICE_OUT_PER_M`(既定は Gemini 3.5 Flash・非グローバル、2026-10-11の公式料金表)。トークン数は応答の `usage_metadata` 由来で、取れない場合は費用が過小になる。**請求そのものを止める仕組みではない**(予算アラートは別途) | 実装済み・実機未確認 |
| D-10 | 自分の手番は既定で先手。`MY_PLAYER_IDS` に自分のIDを入れると自動判定。実IDはリポジトリに置かない | 確定 |
